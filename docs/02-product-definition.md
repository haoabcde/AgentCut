# AgentCut 产品定义

## 1. 产品定位

AgentCut 是面向中文创作者的、本地优先的 Agent 原生视频剪辑基础设施：外部通用 Agent 负责理解、分析、规划和调用结构化工具；本地 Web 编辑器负责可见预览、文字稿、多轨时间线、人工修订、版本与导出。

它不是“又一个带聊天框的剪映”，也不是 prompt-to-video 生成器。第一阶段要证明的价值是：

> 用户把中文口播原片交给任意兼容 Agent，得到一个可解释、可撤销、可人工接管的初剪；人工修改后，Agent 仍能从同一 Timeline IR 继续工作。

## 2. 目标用户

### 2.1 首要用户

- 每周稳定制作中文知识口播的独立创作者、小团队、课程/咨询从业者。
- 已使用 Codex、Claude Code、OpenCode、Cursor、Zed Agent 等通用 Agent，愿意在本地项目目录工作的人。
- 对素材隐私、可控删除、可重复工作流有要求，但不需要专业调色/VFX 的创作者。

### 2.2 次要用户

- 将访谈、播客、直播整理为多个短视频的内容团队。
- 想把视频编辑能力嵌入自身 Agent 或内容生产系统的开发者。

### 2.3 暂非目标

- 依赖手机拍摄、模板和一键发布的纯移动用户。
- 需要电影级调色、复杂合成、多人实时协作的专业后期团队。
- 只想用一句 prompt 生成全 AI 视频、没有现有素材的用户。

## 3. 核心价值主张

1. **开放 Agent 接入**：MCP、CLI、SDK 共用协议，不绑定某个聊天产品。
2. **可控自动剪辑**：自动结果带原因、置信度和风险等级；错删优先于漏删。
3. **人工与 Agent 双向协作**：人工操作也是 EditCommand；Agent 可读取最新 revision 继续编辑。
4. **本地素材默认不出机**：只有明确选择云 Provider 的分析/生成任务才上传必要数据。
5. **中文口播深度**：词级时间戳、语义断句、重复/重说/残句、口头禅、呼吸与上下文联合判断。
6. **可替换基础设施**：Timeline、Provider、Preview、Render 解耦。

## 4. 版本边界

需求中的“第一阶段同时支持口播与访谈”和“第一版优先把中文口播做深”存在范围张力。解决方式是把“第一阶段”定义为 V0.1–V0.3，而不是把两个场景塞进一个首发版本。

### 4.1 V0.1 必须做

- macOS 与 Windows，本地项目目录与本地服务。
- 单个或多个本地视频/音频/图片导入；媒体探测、缩略图、波形、代理。
- 中文 ASR、VAD、标点、词级时间戳；字幕与 Transcript。
- 口播候选：静音、口头禅、填充词、卡顿、重复、残句、重说；三档决策和原因/置信度。
- 自动模式生成初剪；导演模式确认高风险内容取舍。
- 素材库、预览、基础多轨时间线、split/trim/move/delete/ripple delete、字幕修改、缩放、播放头。
- undo/redo、显式版本、Agent 操作记录、用户锁。
- MCP、CLI、TypeScript SDK；事务、幂等、revision conflict。
- FFmpeg 稳定导出；9:16/16:9；基础裁切/人物居中可先用可解释静态/分段框。
- 基础 `StyleSpec`：节奏、镜头长度分布、字幕布局/色彩/分行、转场统计、构图；仅做分析与约束，不保证完整复刻。

### 4.2 V0.1 可选/降级

- 本地 FunASR 不适配时允许用户选择云 ASR。
- 人物跟踪不可用时使用用户可调整的固定 crop。
- 动态图形只支持文字、贴纸、基础 scale/opacity/position；Remotion 作为可选插件。
- 浏览器不支持 codec 时先生成代理，不承诺原素材直接预览。

### 4.3 V0.2

- 更完整的参考视频 StyleSpec、关键词高亮、重点文字、贴纸规则。
- StyleSpec 应用预览与差异解释。
- B-roll 建议与本地/免版权/AI 生成三路选择。
- 用户偏好学习，但任何 learned rule 可查看、关闭和重置。
- 更稳的人物跟踪、分段自动构图和多导出预设。

### 4.4 V0.3

- 访谈 diarization、话题/观点/金句/冲突/故事候选。
- 候选短视频的语义完整度与独立传播价值评分。
- 上下文补齐、主持人问题保留、指代检查、多候选时间线。
- 单机位/多机位基础切换和人物标签。

## 5. 明确不做什么

V0.1 不做：

- 完整剪映/CapCut 替代、专业调色、高级蒙版、复杂抠像、复杂关键帧系统。
- 手机编辑、多人实时协作、云素材库、平台视频下载、直接发布。
- 内置通用 Agent、账户体系、云项目同步、云渲染。
- 承诺所有参考视频风格都能复刻，或复制具体创作者受保护的素材/品牌资产。
- 自研 ASR/VLM/生成模型；大规模接入 Provider。
- 让 Agent 写任意 FFmpeg 命令、SQL、前端状态或项目 JSON。
- 在未经确认时调用付费/上传型 Provider。

## 6. 用户工作流

### 6.1 首次使用

1. 用户在项目目录执行 `agentcut init` 与 `agentcut open`。
2. 本地服务锁定项目，生成短时 UI token，并打开浏览器。
3. 用户导入素材，系统生成 metadata/proxy/waveform。
4. 用户在任意 Agent 中连接 AgentCut MCP，或直接使用 CLI。
5. Agent 查询项目能力和 revision，再开始分析。

### 6.2 中文口播

1. 选择主素材与语言/术语词典。
2. 运行转写，用户可先修正专名。
3. 系统生成删除候选，不直接应用高风险项。
4. 自动模式应用“确定删除”，导演模式对所有内容取舍生成 approval。
5. 用户在 Transcript/时间线修改；修改自动形成 EditCommand。
6. Agent 读取新 revision，补字幕、重点文字、构图和基础风格。
7. 低分辨率预览，运行质量检查。
8. 创建版本并导出。

### 6.3 参考视频

1. 用户自行下载并导入参考视频，标记为 `reference`。
2. 系统提取可复用统计与规则，生成带 provenance/confidence 的 StyleSpec。
3. UI 展示“观察到什么 / 建议采用什么 / 无法可靠推断什么”。
4. 用户选择采用的维度；StyleSpec 变为约束，不直接复制素材或逐镜头结构。
5. Agent 的 edit plan 必须说明哪些操作来自 StyleSpec。

### 6.4 人工修改后继续交给 Agent

- 人工修改和 Agent 修改走同一 command bus。
- 每个事务提交后 revision 增加；Agent 的旧计划若基于旧 revision，服务返回冲突而不是覆盖。
- 用户锁定 clip、range、track 或 property 后，Agent 默认无权改动。
- Agent 可查询自上次 revision 的 diff，重新规划未冲突部分。

## 7. 两种控制模式

### 7.1 自动模式

- 允许自动执行低风险、本地、可逆、预算内操作。
- 高风险内容删除、素材上传、付费生成、覆盖用户锁、最终导出仍需策略许可或显式确认。
- 每个阶段产出可查看 artifact：transcript、candidate set、edit plan、quality report。
- 失败时保留最后一个已提交 revision，不出现“半套时间线”。

### 7.2 导演模式

默认确认点：

- 高风险内容取舍。
- 参考风格维度。
- B-roll/生成素材来源和预算。
- 大于配置阈值的批量时间线修改。
- 最终版本与导出预设。

确认对象必须是结构化 proposal，可逐项接受、拒绝或修改，而不是一个“同意 Agent 所有操作”的总按钮。

## 8. 中文差异化能力

### 8.1 不只按静音删除

候选模型输入至少包含：VAD、词边界、标点/断句、重复覆盖、上下文、停顿、语气、呼吸、用户风格。输出包含：

- `decision`: definite_remove / suggest_remove / suggest_keep
- `reasonCodes`: 机器可统计的原因
- `explanationZh`: 用户可读说明
- `confidence`: 模型置信度
- `risk`: low / medium / high
- `evidenceRanges`: 原始词/音频范围
- `alternatives`: 更保守的修剪方式

### 8.2 可积累资产

- 用户术语词典与发音纠错。
- 用户对停顿、口头禅、重复、呼吸和节奏的保留偏好。
- 已接受/拒绝候选及最终人工修正，不保存原始媒体到云。
- 中文口播 benchmark：专业名词、数字、英文夹杂、方言口音、重复重说、尾音和呼吸。

### 8.3 壁垒判断

中文 ASR 本身不是壁垒。更可能形成壁垒的是：

- 高风险错删率持续下降。
- 能解释和复现每个 cut。
- 用户修改后的规则能迁移到下一个项目。
- StyleSpec、Transcript 和 Timeline 之间有稳定映射。

## 9. 成功指标

### 9.1 北极星指标

`从导入到用户接受的首个可发布版本所需的人工有效编辑时间`。

### 9.2 V0.1 质量指标

| 指标 | 门槛 |
|---|---|
| 高风险自动错删 | 自动模式为 0；高风险必须确认 |
| definite_remove precision | 真实测试集 ≥ 98%，按候选计 |
| 删除边界可用率 | ≥ 95% 无截断音节/吞字，人工盲评 |
| 30 分钟项目命令可恢复 | 崩溃注入后 100% 回到最后提交 revision |
| undo/redo round trip | 属性级等价 100% |
| Agent 与人工并发 | 旧 revision 写入 100% 被拒绝或显式 rebase |
| 预览/导出基础子集 | 抽帧几何误差 ≤ 1 px 或有明确 approximation 警告；音画误差 ≤ 40 ms |
| 导出成功率 | 支持矩阵素材 ≥ 99% |
| 隐私 | 默认流程无素材出机网络请求 |
| 可解释性 | 每个 Agent 事务具备 author/reason/confidence/sourceRevision |

数值是发布门槛草案，技术验证后用 benchmark 基线校准，不允许为通过指标而缩小测试集。

## 10. V0.1 验收场景

1. 10 分钟普通话知识口播，包含 20 个停顿、10 个填充词、5 次重说、3 个专名；系统生成三档候选，用户能逐项审核并得到无吞字初剪。
2. 用户在 Transcript 恢复一句被删内容、在时间线移动一张图，再让另一个 Agent 补重点文字；修改不丢失，Agent 只改未锁区域。
3. 两个 Agent 同时基于 revision 12 提交，其中一个先成功；另一个收到 `REVISION_CONFLICT` 和最小 diff，不发生静默覆盖。
4. 项目在命令提交、代理生成、预览渲染过程中分别强制终止，重启后回到最后完整 revision。
5. 同一项目导出 16:9 和 9:16，字幕安全区、人物 crop、音画同步符合预设。
6. 导入参考视频后，StyleSpec 能展示数据来源、置信度、可采用维度；删除参考素材后仍保留可审计的统计，但不保留未授权画面副本。

## 11. 产品决策记录

| 决策 | 选择 | 放弃 | 重评条件 |
|---|---|---|---|
| 首发场景 | 中文知识口播 | 同时做完整访谈/Vlog/广告 | V0.1 指标达标后进入 V0.3 |
| Agent 形态 | 外部 Agent + MCP/CLI/SDK | 首发内置 Agent | 外部接入留存差或新手成本过高 |
| 运行形态 | 本地服务 + Web | 首发 Electron/Tauri/云站 | 安装、codec、权限问题成为主要流失 |
| 自动化原则 | 低风险自动，高风险确认 | 一键全自动黑箱 | 用户明确配置策略且 benchmark 足够可靠 |
| 竞争策略 | 口播正确性与开放协议 | 完整 NLE 功能数量 | 核心留存已稳定且用户需求集中出现 |
